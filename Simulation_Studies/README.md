# Simulation Studies

These scripts are used to reproduce the simulation experiments in the paper.

- **`Simulation_Study_1.R`**  
  Reproduces the experiments in *Section: Synthetic space–time fields*, including data generation from the non-separable Gneiting covariance model, parameter estimation, and evaluation using RMSE and CRPS.

- **`Simulation_Study_2.ipynb`**  
  Reproduces the experiments in *Section: Scalability on large benchmark data*, using the Second Spatial Statistics Competition datasets (2a and 2b) to evaluate predictive accuracy and scalability.
